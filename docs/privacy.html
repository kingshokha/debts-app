Политика конфиденциальности

Приложение «Долги» для Android · действует с 28 октября 2026 г.

«Долги» — приложение для учёта долгов: кто, сколько и когда должен. Эта страница объясняет, какие данные приложение использует и куда они попадают.

Где хранятся данные

Контакты, операции, группы, заметки, фото контактов и фото паспортов хранятся только на вашем телефоне, в памяти приложения. У разработчика нет сервера: данные не отправляются ни разработчику, ни третьим лицам.

Google Диск (по желанию)

Если вы сами подключите Google Диск в меню «☰ → Google Диск», приложение будет сохранять резервные копии в ваш собственный Google Диск:

  • вход выполняется через Google; приложение получает ваш адрес Gmail, чтобы показать, какой аккаунт подключён;
  • запрашивается только доступ drive.file: приложение видит и изменяет лишь файлы, которые создало само (папку «Долги» с копиями и фото), и не видит остальные файлы на вашем Диске;
  • копии передаются напрямую с телефона в ваш Google Диск и обратно — через серверы Google, без посредников;
  • данные из Google Диска используются только для резервного копирования и восстановления в этом приложении, не передаются третьим лицам, не используются для рекламы и не используются для обучения моделей ИИ.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Камера и фото

Доступ к камере и галерее нужен, только чтобы добавить фото контакта или паспорта. Снимки сохраняются в памяти приложения на телефоне и, если подключён Google Диск, в его резервной копии.

Как удалить данные

  • Удалите контакт в приложении или удалите приложение — данные на телефоне будут удалены.
  • Отключите Google Диск в приложении (это отзывает доступ) и удалите папку «Долги» в Google Диске.
  • Доступ приложения к аккаунту Google можно отозвать и на странице myaccount.google.com/permissions.

Изменения и контакты

Если политика изменится, новая версия появится на этой странице с новой датой. Вопросы можно задать в разделе Issues проекта на GitHub.
